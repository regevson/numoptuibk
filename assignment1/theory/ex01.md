#### Find velocity $v(t)$

- given is $a(t)=A-\kappa v(t)$
	- we know that $a(t)=\dfrac{dv}{dt}$, so
		- $\frac{dv}{dt}=A-\kappa v$

	- separate variables:
		- $\frac{dv}{A-\kappa v}=dt$

- integrate both sides:
	- _use (u)-substitution: $u=A-\kappa v\Rightarrow du=-\kappa,dv$_
	- $\int\frac{1}{A-\kappa v},dv=\int dt$
	- left side $\Rightarrow -\dfrac{1}{\kappa}\ln|A-\kappa v|$, right side $\Rightarrow t+C_1$
	- so $-\frac{1}{\kappa}\ln|A-\kappa v|=t+C_1$

- now solve for $v(t)$:
	- $\ln|A-\kappa v|=-\kappa t-\kappa C_1$
	- $|A-\kappa v|=e^{-\kappa C_1}e^{-\kappa t}$

- absorb the sign and constant: 
	- let $C_2= (+-) e^{-\kappa C_1}$
	- $A-\kappa v=C_2 e^{-\kappa t}$
	- $\kappa v=A-C_2 e^{-\kappa t}$
	- $v(t)=\frac{A}{\kappa}-\frac{C_2}{\kappa}e^{-\kappa t}$
- so we finally have:

$$v(t)=\frac{A}{\kappa}-\frac{C_2}{\kappa}e^{-\kappa t}$$

- now we have to determine $C_2$ 
- we say that: $v(0)=v_0$:
	- $v_0 = v(0) = \frac{A}{\kappa}-\frac{C_2}{\kappa}$
	- $C_2=A-\kappa v_0$
- substitute back:
	- $v(t)=\frac{A}{\kappa}-\frac{A-\kappa v_0}{\kappa}e^{-\kappa t}$
- rearrange:

$$v(t)=\frac{A}{\kappa}+\Big(v_0-\frac{A}{\kappa}\Big)e^{-\kappa t}$$

#### Find position $x(t)$ 

- we know that: $\frac{dx}{dt}=v(t)$ 
- so we have $\dfrac{dx}{dt}=\dfrac{A}{\kappa}+\Big(v_0-\dfrac{A}{\kappa}\Big)e^{-\kappa t}$
- we can integrate both sides to get $x(t)$:
	- $x(t)=\displaystyle\int\frac{A}{\kappa}\ dt + \displaystyle\int\Big(v_0-\frac{A}{\kappa}\Big)e^{-\kappa t}\ dt$

- the first integral:
	- $\displaystyle\int\frac{A}{\kappa}\ dt=\frac{A}{\kappa}t$

- the second integral:
	- _we know $\displaystyle\int e^{ct}\ dt=\frac{1}{c}e^{ct}$
	- so we get $\displaystyle\int\Big(v_0-\frac{A}{\kappa}\Big)e^{-\kappa t} dt=\Big(v_0-\frac{A}{\kappa}\Big)\Big(-\frac{1}{\kappa}e^{-\kappa t}\Big)$

- so finally we have:

$$x(t)=\frac{A}{\kappa}t-\frac{1}{\kappa}\Big(v_0-\frac{A}{\kappa}\Big)e^{-\kappa t}+C_3$$

- no we need to find out $C_3$ 
- we define: $x(0)=x_0$
	- $x_0= x(0) = -\frac{1}{\kappa}\Big(v_0-\frac{A}{\kappa}\Big)+C_3$
	- $C_3=x_0+\frac{1}{\kappa}\Big(v_0-\frac{A}{\kappa}\Big)$

- finally we substitute $C_3$ back:

$$x(t)=\frac{A}{\kappa}t-\frac{1}{\kappa}\Big(v_0-\frac{A}{\kappa}\Big)e^{-\kappa t}+x_0+\frac{1}{\kappa}\Big(v_0-\frac{A}{\kappa}\Big)$$

- we can simplify this to:

$$x(t)=x_0+\frac{1}{\kappa}\Big(At+\big(v_0-\frac{A}{\kappa}\big)(1-e^{-\kappa t})\Big)$$
